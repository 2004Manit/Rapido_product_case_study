# Rapido after dark: a product case study

**Rapido wins the day. It loses the night.** After 9 PM, captains drift home and riders stop trusting the ride.

This case study is built on 70 conversations across Delhi NCR (25 captains, 42 riders, 3 non-riders, Aug–Sep 2026). It includes a playable supply simulation and a recommendation, *Night Shield*, with metrics, a pilot plan and risks.

An independent teardown by Manit Agarwal. Not affiliated with, or endorsed by, Rapido.

## Run locally

```bash
npm install
npm run dev          # local dev server
npm run build        # production build into dist/
npm run sim:analysis # regenerate the 200-night simulation data
```

Built with React, Vite and Framer Motion.
